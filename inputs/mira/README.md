# MIRA revenue files

Put MIRA's two monthly revenue spreadsheets here, exactly as downloaded from MIRA:

- the total revenue collection file (all collections, including dollars converted to rufiyaa)
- the USD revenue collection file

File names don't matter, the script recognises each file from its title. When MIRA publishes a new month,
delete the old file and upload the new one. Keep only one of each, or the update stops with a message
saying which file to remove.

Uploading a file here starts the "Update debt data" workflow, which rebuilds `revenue.json`. The new figures
appear on the revenue page a minute or two later.
